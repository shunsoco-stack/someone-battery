## ポートフォリオ文

### ひとこと

名前も知らない誰かの、いまの残量。匿名の充電残量を、ただ眺めるWebアプリ。

### 紹介文

「誰かの充電」は、世界のどこかにいる人が自分で入力した充電残量を、ランダムに眺めるための小さなWebアプリです。残りわずかならちょっと心配して、100%なら少し大げさに褒める。役に立つ情報を増やすのではなく、知らない誰かの存在を感じる余白を目指しました。

巨大なバッテリーを中心に、ダークトーンと柔らかなライムのミニマルUIを設計。手動入力、匿名の呼び名、相対時刻、端末内の閲覧履歴、共有、PWAに対応しています。端末のバッテリー情報や位置情報は取得せず、投稿は残量・2つの時刻・架空の呼び名だけ。デモと実データを分離し、空の状態や通信エラーも明示する設計にしました。

Next.js・TypeScript・Tailwind CSSで実装し、Firebase匿名認証、Firestore Security Rules、24時間の表示期限とTTL設定を構成。Vercel Analytics向けには、残量や名前を送らず、訪問者ヘッダーを固定化するサーバー中継を実装しています。公開先はHobbyプランのため、カスタムイベントの収集は停止中です。

現在の公開版はデモモードです。新規Firebaseプロジェクトの作成上限により実運用は未接続で、表示されるサンプルと試用投稿は実ユーザーによる投稿ではありません。

### 担当範囲

コンセプト整理、UI/UX、フロントエンド、Firebase接続ロジック、ルール設計、PWA、アイコン・OG画像、テスト、公開手順の整備。

### 技術的なポイント

- 端末の残量を自動取得しない、0〜100の自己申告方式。
- Firebase未設定時だけ明示デモ。実接続エラー時にサンプルへ逃げない状態設計。
- Firestoreの4フィールド完全一致と匿名認証をSecurity Rulesで検証。
- 24時間後の表示除外と、非同期のTTL削除を分けたデータライフサイクル。
- 動きを減らす設定、キーボード操作、読み上げを考慮したインタラクション。

## Tsukutta文

### タイトル

誰かの充電 — 名前も知らない誰かの、いまの残量。

### 本文

世界のどこかにいる人の充電残量を、ただ眺めるWebアプリを作りました。

ボタンを押すと、大きなバッテリーと、ゆるい匿名の呼び名が出てきます。残量が少ないと心配し、100%だとちょっと褒めすぎます。自分の残量はスライダーか数値入力で投稿する仕組みで、端末のバッテリー情報を勝手に読むことはありません。位置情報も使いません。

デザインは、黒に近い背景と柔らかなライム。機能を詰め込むより、数秒だけ知らない誰かを想像できる空気を大切にしました。

公開版はFirebase未接続の「デモモード」です。サンプル表示と、このブラウザー内での投稿体験を試せます。実投稿を共有するFirebase接続用コードと設定手順はGitHubにまとめています。
